# Commandes utilisateur AmigaDOS 1.3

## Commandes pour le traitement des fichiers

| Commande | Description |
|---|---|
| `;` | Caractère précédant un commentaire |
| `<` | Dirige l'entrée des commandes |
| `>` | Dirige la sortie des commandes |
| `COPY` | Copie un fichier dans un autre ou copie tous les fichiers d'un répertoire dans un autre |
| `DELETE` | Efface jusqu'à 10 fichiers ou répertoires |
| `DIR` | Affiche les noms des fichiers dans un répertoire |
| `ED` | Fait entrer dans un éditeur d'écran pour fichiers texte |
| `EDIT` | Fait entrer dans un éditeur par ligne |
| `FILENOTE` | Permet d'attacher une note contenant au plus 80 caractères au fichier spécifié |
| `JOIN` | Concatène jusqu'à 15 fichiers pour former un nouveau fichier |
| `LIST` | Examine et affiche des informations détaillées sur un fichier ou un répertoire |
| `MAKEDIR` | Crée un répertoire ayant un nom spécifique |
| `PROTECT` | Établit un état de protection pour un fichier |
| `RENAME` | Renomme un fichier ou un répertoire |
| `SEARCH` | Cherche dans tous les fichiers d'un répertoire la chaîne de caractères spécifiée |
| `SORT` | Trie des fichiers |
| `TYPE` | Affiche un fichier texte ou hexadécimal à l'écran |

---

## Commandes CLI

| Commande | Description |
|---|---|
| `BREAK` | Active les indicateurs d'alerte pour une procédure donnée |
| `CD` | Appelle un nouveau répertoire et/ou une unité de disquette |
| `ENDCLI` | Achève une procédure interactive CLI |
| `NEWCLI` | Crée une nouvelle procédure interactive CLI |
| `PROMPT` | Change le message du CLI en cours |
| `RUN` | Exécute les commandes sous forme de procédures d'arrière-plan |
| `STACK` | Affiche ou établit la taille de la pile de commandes |
| `STATUS` | Affiche des informations sur les procédures CLI en cours d'exécution |
| `WHY` | Explique pourquoi une commande précédente n'a pas été exécutée |

---

## Contrôle des fichiers de commande

| Commande | Description |
|---|---|
| `ASK` | Écrit un argument à un caractère et demande à l'utilisateur de répondre oui ou non |
| `ECHO` | Affiche le message spécifié dans un argument de commande |
| `EXECUTE` | Exécute un fichier de commandes |
| `FAILAT` | Arrête un fichier de commandes si un programme envoie un code d'erreur supérieur ou égal à ce nombre |
| `IF` | Teste des actions données dans un fichier de commandes |
| `LAB` | Définit un label (voir `SKIP`) |
| `QUIT` | Fait sortir d'un fichier de commandes avec un code d'erreur spécifié |
| `SKIP` | Saute jusqu'à un `LAB` dans un fichier de commandes |
| `WAIT` | Attend pendant un certain temps ou jusqu'à une date définie |

---

## Gestion du système et de la mémoire

| Commande | Description |
|---|---|
| `ASSIGN` | Assigne un nom d'unité logique à un répertoire de gestionnaire de fichiers |
| `DATE` | Affiche ou règle l'heure et la date système |
| `DISKCOPY` | Copie la totalité du contenu d'une disquette sur une autre |
| `FAULT` | Affiche les messages correspondant aux codes d'erreur pris en charge |
| `FORMAT` | Formate et initialise une nouvelle disquette |
| `INFO` | Donne des informations sur le gestionnaire de fichiers |
| `INSTALL` | Transforme une disquette formatée en disquette de lancement |
| `RELABEL` | Change le nom d'une disquette |
| `SETCLOCK` | Commande l'horloge permanente équipée d'une batterie de secours |
